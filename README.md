# MyPortfolio
This is my portfolio. Here is almost all my projects/works on Python and Django(Django's projects is located in directories)

If you want to check my works, then you need to run this commands in your IDLE terminal
(you need to write your name for file instead of 'NAME'. And choose directory where you will keep all my works)
(And you can see directory where python is searching files in terminal, and it tells you where a new file(from a command) will be created at):

1)python -m venv NAME        -- for creating a virtual environment that will be need you to run servers and for other features
2)NAME\Scripts\activate        -- activating your virtual environment(write your virtual environment's name instead of NAME)
3)pip install django        -- installing django(only with Environment ON)

python PROJECTNAME\manage.py runserver(only with Environment ON)
Copy URL from terminal response and paste it in your browser URL string

----------------if you want to create your own projects----------------

4)django-admin startproject NAME        -- if you want to create new project(only with Environment ON)
5)python PROJECTNAME\manage.py startapp NAME        -- if you want to create new app for the project(only with Environment ON)
6)in 'Settings.py' in 'Installed_Apps' add new string APPNAME        -- this is need to connect your app to your project
